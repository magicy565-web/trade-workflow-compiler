## 不可冒充的真实环境限制

- 使用的 Worker、发送回执和买家事件都是 `test/` 中明确标记的合成 fixture，**没有**真实邮箱、OpenMausBot 服务器、供应商、RFQ、订单或财务回款交互。
- `human_reviewed` 只是另一名授权操作员复核了登记的证据指针；不能保证交易真实性、账单准确性或资金到账。
- 不能声称使用过真实 GitHub Actions CI，除非 GitHub 对应提交确实返回运行记录。远端仓库由用户创建；工具发布的实际情况以最终验收说明为准。
- Windows、Docker、生产级负载和完整浏览器 E2E 未在本次环境实际验收。上一版浏览器导航受到策略限制。
- Temporal 调度桥依然可选且未经过实际 SDK/Temporal Server 集成测试；本版验收采用内置 SQLite 调度。
- 此环境未能完成 npm Registry 的全新在线安装；预编译分发版不需要安装运行时依赖。

迁移前请停止旧服务并备份 `data/` 与 `.env`。schema 3 不能由旧版本直接打开；回滚需要恢复备份、核对远端发送状态。
